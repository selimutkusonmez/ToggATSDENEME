# IT Entegrasyon Talebi – Kısa Özet

Hazırlanan TOGG Deneyim Merkezi Çorlu Servis Takip ve Yönetim Sistemi'nin mevcut kurumsal veri kaynaklarıyla güvenli şekilde entegre edilmesi talep edilmektedir.

**Öncelik:** Kurumsal API / web servis / read-only entegrasyon. Doğrudan veritabanı erişimi ancak IT tarafından uygun görülürse değerlendirilmelidir.

**Hedeflenen veriler:** plaka, VIN/şasi, model, batarya tipi, servis kabulü, süreç, arıza/talep, teknik veriler, parça/değişim, randevu ve teslimat bilgileri.

**IT'den beklenen:** uygun veri kaynağı, API dokümantasyonu, test ortamı, kimlik doğrulama yöntemi, ağ/VPN gereksinimleri, veri güvenliği ve canlıya alma prosedürü.

Geliştiren: Aleyna Uzun – 2026
